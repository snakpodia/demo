Installation and Project Running Rubric

## Getting started

----
- Before cloning the repo Ensure Xcode is installed on your System for Mac 
 
### Clone Repository

----
- [ ] Create a directory to clone the script with `mkdir <name of your desired folder>`
- [ ] Navigate into the folder with `cd <name of the folder that you just created>`
- [ ] Copy and Paste this `git clone git@github.com:stephtakehome/automation.git`
- [ ] Navigate in to the repository
- [ ] Open the repository and run `npm ci` to run a clean install
----

### Running the project

---

- [ ] Open your preferred IDE eg Visual Studio
- [ ] Open Terminal
- [ ] Run the script on the terminal headless - npx cypress run 
- [ ] Run the script on the terminal headed - npx cypress run  --headed
